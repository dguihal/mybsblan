# 📘 Paramètre `561` : Progr. commande horaire 4 (Lundi)

Ce paramètre définit l'ensemble des plages horaires d'autorisation de chauffe de l'eau chaude sanitaire (ECS) attribuées pour la journée du **lundi** dans le **Programme 4**.

> [!NOTE]
> Ce programme horaire est appliqué par le régulateur lorsque la libération ECS ([`1620`](1620.md)) est réglée sur **`2` (Programme horaire 4/ECS)** ou **`4` (Prog. horaire 4/ECS ou THC)**.

---

## ⚙️ Format et Syntaxe

Le paramètre est une chaîne de caractères contenant **jusqu'à 3 plages horaires actives** séparées par un espace.

| Élément | Format / Syntaxe | Description |
| :--- | :--- | :--- |
| **Structure** | `HH:MM-HH:MM HH:MM-HH:MM HH:MM-HH:MM` | Représente respectivement la Phase 1, Phase 2 et Phase 3. |
| **Granularité** | **10 minutes** | Les heures/minutes évoluent par pas de 10 min (ex. `05:10`, `21:30`). |
| **Plage désactivée** | **`##:##-##:##`** | Indique qu'un créneau horaire n'est pas utilisé. |
